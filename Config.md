## Local Model Setup (Future)

### Ollama Configuration

```yaml
# docker-compose.yml (for local development)
services:
  ollama:
    image: ollama/ollama:latest
    ports:
      - "11434:11434"
    volumes:
      - ollama_data:/root/.ollama
    
volumes:
  ollama_data:
```

### Recommended Local Models

| Model | Size | Use Case |
|-------|------|----------|
| `llama3.2:8b` | 4.7GB | General chat |
| `llama3.2:70b` | 40GB | Complex reasoning |
| `mistral:7b` | 4.1GB | Fast responses |
| `codellama:34b` | 19GB | Code generation |
| `phi3:3.8b` | 2.2GB | Quick classification |

### Task Routing Logic

```
Complexity Score < 0.6 → Local Model
Complexity Score >= 0.6 → Lovable AI
Vision Required → Lovable AI (Gemini)
Local Unavailable → Lovable AI
```

## Provider Configuration UI

### Supported Providers
1. **Lovable Cloud** - Default, fully managed
2. **Local Storage** - Browser-based (IndexedDB)
3. **Local Server** - Self-hosted backend
4. **AWS S3** - Amazon storage
5. **GCP Storage** - Google Cloud
6. **Azure Blob** - Microsoft Azure
7. **Custom API** - Any REST endpoint

### Database Table: `provider_config`

| Column | Type | Description |
|--------|------|-------------|
| `id` | UUID | Primary key |
| `user_id` | UUID | Owner |
| `data_type` | String | tasks, contacts, documents, etc. |
| `provider` | Enum | Storage provider |
| `is_active` | Boolean | Currently in use |
| `sync_enabled` | Boolean | Cross-provider sync |
| `fallback_provider` | Enum | Backup provider |
